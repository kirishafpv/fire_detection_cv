# 🔥 Fire Detection System using Drone and Computer Vision

Система автоматического обнаружения пожаров на основе компьютерного
зрения, нейронных сетей и беспилотного летательного аппарата.

Проект демонстрирует, как можно объединить FPV‑дрон, потоковое видео и
нейросетевые алгоритмы для автоматического обнаружения очагов
возгорания.

------------------------------------------------------------------------

# 🚁 Описание проекта

В рамках проекта разработана система обнаружения пожаров, которая
анализирует изображения и видеопоток с камеры дрона и автоматически
определяет наличие огня.

Система использует несколько моделей машинного обучения:

-   ResNet18 --- классификация изображения (есть пожар / нет пожара)
-   YOLOv8 --- детекция и локализация области огня
-   Grad‑CAM --- визуализация областей внимания нейросети

Интерфейс системы реализован в виде веб‑приложения на Python с
использованием Streamlit.

# 🚁 Используемый дрон

В проекте использовался FPV‑дрон размером 2.5 дюйма, оснащённый цифровой
системой передачи видео DJI O4.

Основные характеристики:

-   FPV drone 2.5 inch
-   цифровая камера DJI
-   система передачи видео DJI O4
-   потоковая передача видео через RTMP

Цифровая система DJI обеспечивает высокое качество изображения и низкую
задержку передачи сигнала.

------------------------------------------------------------------------

# 📡 Передача видеопотока

Видеопоток с дрона передается на наземную станцию и далее на компьютер
через RTMP‑сервер.

Схема передачи:

Drone Camera\
↓\
DJI O4 Transmission\
↓\
Ground Receiver\
↓\
RTMP Streaming Server\
↓\
Computer Vision System

Это позволяет анализировать видеопоток в реальном времени.

# 🧠 Используемые модели

## ResNet18

Используется для классификации изображений.

Классы:

fire\
no_fire

Файл весов:

fire_model.pth

------------------------------------------------------------------------

## YOLOv8

Используется для детекции огня на изображении.

Позволяет:

-   обнаруживать огонь
-   выделять bounding box
-   показывать confidence

Файл весов:

best.pt

------------------------------------------------------------------------

## Grad‑CAM

Метод интерпретации нейронных сетей.

Позволяет визуализировать области изображения, на которые нейросеть
обращает внимание при принятии решения.
